# 桃喜团子收银系统 · 使用说明（店内电脑版 v1.3.1）

## 一、安装（只需做一次）

适用于 **Windows 10 或 Windows 11（64 位）** 的电脑。压缩包里已经带了运行环境，不用另外安装任何软件。

1. 把压缩包解压，得到"桃喜团子收银系统"文件夹，放到一个固定位置，例如桌面或 `D:\收银系统`。不要在压缩包里直接双击运行。
2. 双击文件夹里的 **启动收银系统.bat**。

文件夹里各个东西是做什么的：

| 名称 | 说明 |
| --- | --- |
| 启动收银系统.bat | 每天开店双击这个 |
| 使用说明.html | 就是这份说明 |
| app | 程序文件，不用动 |
| data | 第一次启动后才出现，所有账目、照片和备份都在这里，千万别删 |

> Windows 7 和 32 位系统用不了。不确定的话：在"此电脑"上右键 → 属性，看"系统类型"和 Windows 版本。

### 从旧版本升级

**从 v1.1.2、v1.2 或 v1.3 升级**：关掉黑色窗口，把旧文件夹里的 **app** 文件夹删掉，换成新版的 app 文件夹，再把新版的 使用说明.html 和 允许手机连接.bat 复制过去。data 文件夹不要动。

**从更早的版本升级**：

1. 关掉正在运行的黑色窗口。
2. 旧文件夹里除了 **data** 文件夹，其他文件和文件夹都可以删掉。
3. 把新版文件夹里的所有东西复制到旧文件夹里。
4. 双击 **启动收银系统.bat**。旧数据会自动升级。

## 二、每天启动

1. 双击 **启动收银系统.bat**，会弹出一个黑色窗口，浏览器也会自动打开收银页面。
2. **黑色窗口不要关**，关了收银系统就停了。用完可以关掉，下次再双击打开。
3. 柜台平板、手机连上店里**同一个 WiFi**，打开黑色窗口里"平板/手机打开"后面的地址。可以在浏览器菜单里选"添加到主屏幕"，以后像 App 一样点开。
4. 把黑色窗口里"顾客查询页"的地址做成二维码贴在柜台（任意二维码生成器都行）。顾客连上店里 WiFi 后扫码，输入 5 位码查询。

黑色窗口里的内容类似这样：

```
桃喜团子收银系统已启动（版本 1.3.0）

收银页面已经在浏览器里打开了。没打开的话，在浏览器地址栏输入 http://localhost:3000
平板/手机打开： http://192.168.1.23:3000
顾客查询页：    http://192.168.1.23:3000/q
```

> 建议在路由器里给这台电脑设置固定 IP，否则重启路由器后地址可能变化，二维码要重做。

### 打不开怎么办

- **弹出"Windows 已保护你的电脑"**：点"更多信息"，再点"仍要运行"。
- **弹出"打开文件 - 安全警告"**：点"运行"。
- **弹出防火墙提示（名字是 Node.js），或者 360、火绒拦截**：选"允许"。不允许的话，平板和手机连不上。

### 手机、平板连不上

1. 手机要连**店里同一个 WiFi**（不是 4G/5G 流量）。
2. 双击收银系统文件夹里的 **"允许手机连接.bat"**，弹出"是否允许此应用对你的设备进行更改"点"是"，看到"已放行"就好。只需做一次，收银系统的黑色窗口不用关。
3. 手机浏览器输入黑色窗口里"平板/手机打开"后面的地址，注意是 `http://` 开头，后面要带 `:3000`。窗口里有好几行地址的话，一般是 `192.168.` 开头那行，逐个试一下。
4. 装了 360、火绒、电脑管家的，在它们的防火墙里也允许 Node.js。
5. 还是打不开：很可能是学校、商场的公共 WiFi 不让设备之间互相访问。可以在店里放一个自己的路由器，电脑和手机都连它；或者用下面的"外网访问"。
- **浏览器没有自动打开**：自己打开 Edge 浏览器，在地址栏输入 `localhost:3000` 回车。
- **提示"收银系统已经在运行了"**：说明之前已经开过一个黑色窗口，用那个就行。
- **黑色窗口一闪就没了，或者里面有报错**：把黑色窗口截图发给我们。
- **不要双击 app 文件夹里的 server.js 之类的文件**，那是程序文件，双击会报错。

## 三、第一次登录

- 员工选"店主"，密码 **123456**。登录后马上到"设置 → 我的密码"修改。
- 在"设置"里：
  - 修改商品（系统自带了几个示例商品，可以改名、改价或下架）
  - 填写学校餐票的面额（例如 10,20）
  - 添加收银员和后厨的账号
  - 在"盘存"页新增或批量导入原料、包材，再到"设置 → 产品配方"给每个商品设配方（做 1 个用多少原料、包材）
  - 要打折的话，在"打折"里开启，并设好 3 个折扣按钮（例如 9、8.5、8 折）
  - 有小票打印机的话，设置打印机（见第六节）

## 四、各页面做什么

| 页面 | 谁能用 | 做什么 |
| --- | --- | --- |
| 收银 | 店主、收银员 | 点商品 → 选现金 / 收银机 / 临时用票 / 存票余额 结账；可打折、拍照、打印小票。商品按近 30 天销量排，卖得多的在前；卡片上显示今日已售、目前库存、剩余待做 |
| 存票 | 店主、收银员 | 存票开户（生成 5 位码）、续存、查看流水、打印凭条；店主可调整、重置码、销户 |
| 订单 | 店主、收银员 | 查看每天订单、补打小票；店主可撤单（存票扣款自动退回） |
| 日结 | 店主、收银员 | 收档时核对现金、学校收银机小票和店内余票，可打印日结单 |
| 出品 | 店主、后厨 | 出品表列出前一天做的生产计划，逐行登记出炉、报损、收档剩余；计划外的商品和新品也能登记 |
| 生产计划 | 店主、后厨 | 系统按历史销量建议明天做多少，店主改数后保存 |
| 盘存 | 店主、后厨 | 按原料、包材、成品（按商品分类）列出理论库存，填实盘数后保存；入库、领用、损耗；批量导入库存品 |
| 餐票 | 店主 | 票据库存金额；去学校兑换、自由出库（填金额就行）；"票据记录"里看所有收票和出库 |
| 报表 | 店主 | 四种来源金额、商品销量、时段分布；导出 Excel |
| 设置 | 店主 | 店名、商品、员工、餐票面额、小票打印机、密码、备份、操作日志 |

页面上的每个表格下面都有"导出 Excel"和"打印"两个按钮。打印用的是 Windows 默认打印机（A4），在打印窗口里也可以选"另存为 PDF"。

## 五、几个规则

- **打折**：收银页面点"9折""8.5折"这些按钮，只对这一单有效；点"其他"可以输入任意折扣。勾选"全部订单打折"后，所有平板和手机收银时每一单都自动打这个折扣，做活动结束后记得取消勾选。小票上会印出原价和优惠金额。报表里商品销量的金额按原价算，营业额按打折后算。
- **店内余票**：日结时数一下店里还有多少张纸质餐票，按面额填张数，系统算出合计金额，和票据库存比。票据库存 = 收进来的临时用票和存票纸票，减去去学校兑换和自由出库的金额。有差额要填原因。
- **票据出库**：在"餐票"页点"去学校兑换"或"自由出库"（例如拿去其他档口用），只填金额，从票据库存里扣。所有收票和出库都在"票据记录"里，可以按日期查、导出、打印。
- **出品表**：前一天在"生产计划"页保存好第二天的计划，第二天出品页就会自动列出来。每一行填数量后点"出炉""报损"或"剩余"。新品在"登记出品"里选"＋ 新品"，填名称和售价，会同时加到商品里。
- **库存怎么联动**：后厨登记"出炉"时，按产品配方自动扣原料和包材（删掉这条出炉记录会退回）。成品库存 = 出炉 − 售出 − 报损，收银卖出就自动减。从没登记过出炉的商品显示"—"。
- **规格**：原料可以设规格，例如面粉主单位 kg、规格 25 kg/袋。入库时选"按袋"填 1，库存加 25 kg。配方和库存都按主单位算。
- **批量导入**：在"盘存"页点"批量导入"，先下载模板，在 Excel 里填好后整块复制粘贴进去（或选 CSV 文件）。同名的会更新资料。
- **原材料订购计划**：在"生产计划"页最下面，选从哪天起算几天，系统按这几天的计划（没保存计划的用建议数）和配方算出要用多少原料，减去现有库存、加上预警量，得出建议采购多少（按整袋向上取整）。
- **利润**："报表"页最上面是"今天赚了多少" = 营业收入 − 今天出炉用掉的原料成本 − 原料损耗。成本按配方和库存品单价算，不算房租、人工、水电；没设配方的商品成本按 0 算。下面按分类和商品列出售出、销售额、成本、毛利。
- **盘点**：在"盘存"页先点表格下面的"打印"，打一张盘存表去清点，回来把实际数量填到"实盘"一栏（没清点的留空），点"保存盘点"，系统按实盘数修正库存。

- **餐票不找零**：临时用票的票面超过商品金额时不退钱。例如 26 元的商品收 3 张 10 元票，就按 30 元票结账，多出的 4 元记为"餐票溢收"，算在临时用票的金额里。如果少收一张票也够付（比如 26 元收了 4 张 10 元票），系统会提醒并且不让结账。
- **餐票不够**：票面不够时，差额选现金或收银机补齐。全用餐票时才会有溢收，混着现金付不会多收。
- **存票余额不够**：自动算出差额，选现金或收银机补齐。
- **查询码安全**：顾客查询页同一台设备连续输错 5 次锁 15 分钟；全店每分钟最多 60 次查询。顾客页和小票上只显示姓氏加星号。
- **收银、出品、盘存目前互相独立**：卖出不会自动扣库存。报表里会把"售出"和"出炉"并排给你对照。

## 六、小票打印机

### 还没买的话怎么选

选 **58 毫米或 80 毫米的热敏小票打印机**，支持 ESC/POS 指令（市面上常见的国产小票机基本都支持，买之前问一下商家）。

- **带网口（或 WiFi）的最方便**：打印机接到路由器上，平板、手机、电脑收银都能出小票，打印机可以放在柜台任何位置。
- **只有 USB 的**：要插在运行收银系统的那台电脑上，平板和手机收银时也能出小票，但打印机得放在电脑旁边。

### 设置方法

店主登录后进"设置 → 小票打印机"，选打印方式，填好后点"保存并测试打印"，能打出一张"打印测试"就说明成功了。

1. **网络打印机（网口或 WiFi）**
   - 打印机用网线接到路由器（或按说明书连上店里 WiFi）。
   - 查打印机的 IP 地址：多数打印机关机后按住走纸键再开机，会打出一张自检页，上面有 IP 地址。
   - 把 IP 填进去，端口一般是 9100，不用改。
   - 建议在路由器里给打印机固定 IP。

2. **USB 打印机（连在这台电脑上）**
   - 先装好打印机自带的驱动，确认 Windows 能识别。
   - 在 Windows 里共享打印机：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 点这台打印机 → 打印机属性 → "共享"页 → 勾选"共享这台打印机"，共享名填英文或数字，例如 `POS58`。
   - 把这个共享名填到收银系统里。
   - 如果测试打印出来是乱码或空白，把这台打印机的驱动换成 Windows 自带的"Generic / Text Only"再试。
   - Mac 电脑：填"系统设置 → 打印机"里显示的打印机名称。

3. **浏览器打印**
   - 每次打印会弹出浏览器的打印窗口，只适合直接在这台电脑上收银时用。
   - 先在 Windows 里把小票打印机设成默认打印机。
   - **免确认打印**：先把 Edge 浏览器全部关掉，在桌面新建一个快捷方式，位置填：
     `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk-printing http://localhost:3000`
     以后用这个快捷方式打开收银系统，打印时就不再弹窗，直接从默认打印机出纸。

### 能打印什么

- **销售小票**：结账后在购物车上方点"打印小票"，或在"订单"页补打。存票消费的小票上会印出剩余余额。
- **自动打印**：可以设成"每单都打印"或"只打存票消费的单"。
- **存票凭条**：开户或重置查询码后点"打印凭条"，上面有 5 位查询码和查询方法，交给顾客保管。账户详情里还能打印"余额凭条"（只显示查询码后两位）。
- **日结单**：在"日结"页点"打印日结单"，留作纸质记录。
- 如果每行文字对不齐（右边被截断或空太多），在设置里填"每行字数"：58 毫米一般是 32，80 毫米一般是 48，有的打印机是 42。

## 七、外网访问（手机用流量也能打开）

收银系统装在店里电脑上，正常只有店里 WiFi 能打开。想在店外用手机流量看报表、收银，可以装一个免费的"内网穿透"软件 **cpolar**，它会给收银系统一个外网网址。店里电脑要开着、收银系统要开着才能用。

1. 在店里电脑上打开 cpolar 官网 `www.cpolar.com`，注册账号，下载 Windows 版安装。
2. 安装好后浏览器打开 `http://localhost:9200`，用刚注册的账号登录。
3. 左边点"隧道管理" → "创建隧道"：隧道名称随便填（比如 收银），协议选 **http**，本地地址填 **3000**，域名类型选"随机域名"，地区选 **China**，点"创建"。
4. 左边点"状态" → "在线隧道列表"，能看到一个 `https://` 开头的网址，手机用流量打开它，就是收银系统登录页。
5. cpolar 会跟着电脑开机自动启动。**免费版的网址每天会变**，每次在第 4 步里看最新的；想要固定网址需要买 cpolar 的付费版，或者以后把系统搬到云服务器。

注意：

- 外网谁都能打开登录页，**开外网前先在店里电脑上把默认密码 123456 改掉**（店主在"设置 → 我的密码"里改，员工的密码在"设置 → 员工"里改），每个员工用不同的密码。还是 123456 的账号，从外网登录会被拒绝。密码连续输错 5 次，这台手机会被锁 15 分钟；同一个人被输错 10 次，这个人也锁 15 分钟（已经登录的设备不受影响；急用的话，关掉收银系统黑色窗口重新启动就解锁）。
- 顾客查询页也能用外网网址打开：网址后面加 `/q`。因为免费网址每天会变，暂时不适合印在小票上给顾客。
- 5 位查询码只有 9 万种，放到外网上有人可能一个个去试。所以外网查询码一小时内总共输错 30 次，外网查询就暂停到下个小时（店里 WiFi 查询不受影响）。万一被试中，对方能看到的是打了码的名字、余额和消费记录。
- cpolar 的界面以后可能会改版，按钮名字对不上的话按意思找。

## 八、数据和备份

- 所有数据在 `data` 文件夹里：`shop.db` 是数据库，`photos` 是消费照片，`backups` 是自动备份（每 6 小时一份，保留最近 60 份）。
- **建议每周把整个 `data` 文件夹复制到 U 盘或网盘。** 电脑坏了，在新电脑上解压一份新的收银系统，把 `data` 文件夹放回去就能接着用。
- 换电脑：把整个文件夹（含 `data`）复制过去即可。

## 九、本地版的限制

- 不装内网穿透的话，顾客只有连上店里 WiFi 才能查询。以后如果要让顾客随时随地查、网址固定不变，需要把系统搬到云服务器，数据可以原样迁移。
- 电脑关机时，平板和手机也无法收银，也打不了小票。
