# 车间出率与成本核算系统 · 使用说明

系统按天运行：统计分析员每天录入车间称重和抄表数据，录完系统就算出当天每种原料、每道工序的实际出率，再逐级推出半成品和成品的实际成本、标准成本，偏差超限的自动标红。同时用抄表数据算出电、水、燃气的吨能耗。重量单位统一为斤。

## 一、安装与启动

1. 在厂里一台常开的 Windows 电脑上安装 Python 3.11 或更高版本（https://www.python.org/downloads/ ，安装时勾选 “Add python.exe to PATH”）。
2. 把整个 `amibo-system` 文件夹复制到这台电脑上。
3. 双击 `启动系统.bat`。第一次运行会联网安装依赖、初始化数据库，之后直接启动。
4. 浏览器会自动打开 http://127.0.0.1:8000 。平板或其他电脑连同一个局域网，用这台电脑的 IP 打开，例如 `http://192.168.1.10:8000`。

关掉黑色窗口就停止系统。Mac 或 Linux 用 `start.sh`。

**数据备份**：所有数据都在 `data/amibo.db` 这一个文件里。关掉系统后复制这个文件即可备份，建议每周拷一份到 U 盘或网盘。

**想先试用**：在 `backend` 文件夹里运行 `.venv\Scripts\python -m app.seed --reset --demo`，会清空数据库并放入 2026-10-12 至 10-14 三天的示例数据（单价、出率都是编的）。正式使用前再运行 `.venv\Scripts\python -m app.seed --reset` 清空。

## 二、第一次使用：先把基础资料建好

按这个顺序在“基础资料”菜单里维护。会变的资料（标准出率、BOM、干调价、袋费、能源单价、计量表配置）都带生效日期，改了不会覆盖历史，历史日期仍按当时的版本计算。

| 步骤 | 页面 | 要做的事 |
| --- | --- | --- |
| 1 | 原料 | 建所有原料（含干调、水、芝麻），填编码（与 T+ 存货编码一致）、类别、是否需要 1→2 级处理、标准出率。可用“Excel 导入”批量导入 |
| 2 | 干调价格 | 每种干调填单价（元/斤）和生效日期 |
| 3 | 产品 | 建成品馅、半成品油、麻油；勾选是否经过制冷、是否包装；填各环节标准出率。麻油要选芝麻原料 |
| 4 | BOM | 每个产品一份，每锅（每机）投多少斤。可从 Excel 导入 |
| 5 | 包装规格 | 已建好 2/5/15/20 斤袋，**袋费目前是 0，等工厂给出袋费清单后填上** |
| 6 | 计量表 | 已按需求文档建好 25 块表（倍率、计入方式），一般不用动 |
| 7 | 能源单价 | 已填水 4.49、电 0.8644、燃气 4.3741（未税） |
| 8 | 预警阈值 | 全局默认 ±3 个百分点；蔬菜、泡发、酱腌等波动大的类别可以单独设 |

需求文档附录里的“粉丝馅料”“蛋白鲜肉馅料”两个 BOM 已经建好，可以直接用来核对。

## 三、每天怎么用

打开“每日录入”，选好日期，按车间纸质记录逐页填写，每页填完点保存：

1. **原料单价**：上传当天 T+ 导出的 Excel，系统按编码（其次名称）匹配原料。没匹配上的行会列出来，去原料资料里补上编码后重新上传即可。也可以手工填。
2. **原料处理**：需要处理的原料填 1 级领用量、2 级称重。没处理的原料按标准出率计算。
3. **制馅**：当天生产的产品填锅数（机数）和出锅重（出机重）。
4. **麻油**：芝麻用量、麻油产量。
5. **制冷**：经过制冷的产品填打冷出机重。
6. **包装**：包装入库量和各规格袋数。包装前重量默认取上一环节产出，一般不用填。
7. **抄表**：每块表填本期读数，上期自动带出。光伏填当日发电量。换表当天点“换表”，填旧表最终读数和新表起始读数。

每次保存后系统立即重算，页面下方会列出当天的超限项和提示（缺单价、缺记录、读数变小、疑似录错等）。

录完后看“今日概览”和“异常清单”，异常项查到原因后可以在异常清单里填写原因备注。

## 四、报表

所有报表都可选日期区间，并可导出 Excel。

- **出率日报**：各原料 1→2 级出率、各产品各环节出率，实际 / 标准 / 偏差，超限标红。
- **成本日报**：各产品出机、冷后、成品单价，实际 / 标准 / 差额。
- **成本链路查询**：选一个产品和日期，从 1 级原料逐级展开到成品，看每一层用了哪些料、单价多少、出率多少，以及差额归因：依次把每个环节的实际出率换成标准，看是哪种原料或哪道工序拉高了成本。
- **异常清单**：超限项和提示，可填原因备注。
- **能耗日报 / 月报**：每块表用量、各合计、吨能耗、能耗费用。月报按日列出，月合计的吨能耗 = 月合计用量 ÷ 月合计产量。
- **趋势**：任选原料、产品或能耗指标看按日走势。

## 五、计算口径（与需求文档一致）

- 出率 = 产出重量 ÷ 投入重量，按天计算。
- 2 级单价 = 当天 1 级单价 ÷ 当天 1→2 级出率；不需要处理的原料出率固定 100%。
- 投料成本 = 锅数 × Σ（BOM 每行数量 × 该行单价）；出机单价 = 投料成本 ÷ 出锅重。
- 冷后单价 = 出机单价 ÷ 制冷出率。
- 成品单价 =（包装前单价 × 包装前重量 + Σ 袋数 × 袋费）÷ 包装入库量。
- 麻油单价 = 芝麻 1 级单价 ÷ 麻油出率。
- 标准成本：同一套公式，把每个实际出率换成标准出率，单价不变。差额全部来自出率偏差。
- 当日总产量 = 各产品包装入库量 + 麻油产量；吨 = 斤 ÷ 2000。
- 缺原料单价的产品不出成本并提示，不自动取旧价。
- 显示精度：重量 2 位小数，单价 4 位，出率到 0.01%；中间计算不四舍五入。

## 六、待确认事项的当前做法

以下按需求文档给的默认做法实现，工厂答复后在“系统设置”或对应资料里改，不用改程序：

| 事项 | 当前做法 | 在哪里改 |
| --- | --- | --- |
| 麻油“取前一周”的口径 | 前 7 天按产量加权平均 | 系统设置（可改为上一自然周） |
| 半成品油前一天没熬 | 取最近一次熬制的实际冷后单价；再没有就用产品资料里的“标准单价” | 产品资料 |
| 包装入库量 | 单独录入；袋数 × 每袋斤数与入库量相差超过 5% 时提示 | — |
| 烧麦豆沙组哪些产品经过制冷 | 在产品资料里逐个勾选 | 产品资料 |
| 偏差预警全局阈值 | ±3 个百分点 | 系统设置 |
| 研发室燃气 | “参考”，不计入合计 | 计量表 |
| 储福记燃气 | 读数差 ÷ 1000 × 80，从全厂合计扣减 | 计量表 |
| 井水 | 计入全厂和车间合计，按水价计费 | 计量表 |
| 现有能耗表的重复扣减等问题 | 储#1、储#2 只扣一次，统一用维护的单价 | — |

还需要工厂提供：各包装规格的袋费、各干调单价、各原料和各产品环节的标准出率、T+ 单价导出文件的样例（用来确认单价列是含税还是不含税，目前优先取“无税单价/不含税单价/单价”列）。

## 七、已知限制

- 没有登录和权限控制，只适合在厂内局域网使用。
- T+ 导出如果是旧版 .xls，需要先在 Excel 里另存为 .xlsx。
- 还没有用工厂现有 Excel 的历史数据做对账，拿到历史数据后可以导入核对。
