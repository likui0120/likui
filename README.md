# 桃喜团子收银系统

药科大学食堂桃喜团子档口的收银系统，在店里的 Windows 电脑上运行，柜台平板和手机连店里 WiFi 用浏览器打开。

- 四种收款：现金、学校收银机、临时用票、存票余额（5 位查询码）
- 存票、订单、日结、出品、生产计划、盘存、餐票、报表、设置
- 小票打印机（ESC/POS，58/80 毫米）

## 运行

需要 Node.js 22.13 或更高版本，没有其他依赖。

```
cd app
node server.js --open
```

数据保存在 `data/`（不进仓库）。店里用的是免安装版：用 `tools/build.sh` 把官方 node.exe 一起打包成 zip，双击 `启动收银系统.bat` 就能用。使用方法见 [app/使用说明.md](app/使用说明.md)。

## 版本管理

- `main` 分支是店里正在用的、已确认的版本，每个版本打一个标签（例如 `v1.1.2`）。
- 新版本先放在单独的分支上开 Pull Request，店主试用确认后再合并到 `main`，替换旧版本。
